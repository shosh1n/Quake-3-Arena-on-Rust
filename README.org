* README

This project is a port of the game Quake 3 Arena in rust. Its main intend is to teach me rust.
** Credit to ioq3
The code in this repository is inspired by the fork of ioq3. Their code is available on github.
As a foundation I use the *ioq3 version* of Quake 3 Arena, it is compatible with the modern C/C++
toolchain.

Taken from their repository:

=qcommon= is good starting point for developing. It contains necessary IO-methods for game content.
Further meticulous separation is advised in rust as I would not coding on network or Huffman coding
for network gaming to begin with.
